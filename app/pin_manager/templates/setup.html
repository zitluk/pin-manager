Nastavení zařízení

Aby se u blokovaných stránek (i YouTube přes HTTPS) zobrazil formulář s PINem, musí zařízení používat domácí DNS a důvěřovat domácímu certifikátu. Tato stránka to na tomto zařízení ověří.

iPhone / iPad

  1. Otevřete tuto stránku v Safari a stáhněte profil: Stáhnout profil
  2. Nastavení → Profil stažen → Instalovat.
  3. Nutné: Nastavení → Obecné → Informace → Nastavení důvěryhodnosti certifikátů → zapnout {{ ca_name }}.
  4. Nastavení → [vaše jméno] → iCloud → Soukromý přenos vypnout (síť ho blokuje, ale vypnutí zabrání hláškám).
  5. Wi-Fi: u domácí sítě vypnout Omezit sledování IP adresy a nemít ručně nastavené DNS.

Mac

  1. Stáhněte profil nebo certifikát (.crt).
  2. Profil: Nastavení systému → Obecné → Správa zařízení → nainstalovat.
    Certifikát: otevřít v Klíčence → dvakrát kliknout na {{ ca_name }} → Důvěra → Při použití tohoto certifikátu: Vždy důvěřovat.
  3. Zavřete a znovu otevřete Safari.

Windows / Android

  1. Stáhněte certifikát (.crt).
  2. Windows: otevřít → Nainstalovat certifikát → Místní počítač → Důvěryhodné kořenové certifikační autority.
  3. Android: Nastavení → Zabezpečení → Šifrování a pověření → Instalovat certifikát → Certifikát CA.
  4. V Chrome vypnout Nastavení → Ochrana soukromí → Používat zabezpečené DNS.
